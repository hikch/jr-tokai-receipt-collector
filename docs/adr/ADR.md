# ADR Journal

- 2025-09-05: AppleScript+Safari自動化採用。理由: macOSシステムダイアログ制御とPDF保存確実性。却下: Playwright/Selenium。
- 2025-09-05: 外部JavaScript分離採用。理由: メンテナンス性向上とロジック分離。却下: AppleScript内JavaScript埋め込み。
- 2025-09-05: ES5互換JavaScript採用。理由: SafariのAppleScript JavaScript実行環境対応。却下: モダンJavaScript構文。
- 2025-09-05: 領収書画面からの動的ファイル名生成採用。理由: 一覧画面データ不確実性対策。却下: 一覧画面データ使用。
- 2025-09-05: サイト標準期間選択機能使用採用。理由: UI変更耐性とユーザビリティ。却下: 独自日付フィルタ実装。
- 2025-09-05: コンテンツ変化による遷移検出採用。理由: URL不変サイトでの確実なページ遷移判定。却下: URL変化監視。
- 2025-09-05: 固定値cfEXPY_doAction('RSWP360AIDP015')採用。理由: 次ページ機能の確実性。却下: 動的パラメータ抽出。
- 2025-09-05: DRY_RUN機能削除。理由: 実用性低く複雑性増加。却下: プレビュー機能維持。
- 2025-09-05: 環境変数による宛名入力採用。理由: 確定申告用途で宛名必須。却下: 手動入力・設定ファイル方式。
- 2025-09-05: do shell script環境変数取得採用。理由: UTF-8日本語文字化け対策。却下: system attribute使用。
- 2025-09-05: PROCESS_ALL機能削除。理由: Web側期間選択で十分・ロジック重複回避。却下: 単件処理オプション維持。
- 2026-11-09: Playwright(Chromium)+page.pdf()採用。理由: 印刷ダイアログのGUIタイミング問題を根本解決。却下: AppleScript継続改修。
- 2026-11-09: headless:false採用。理由: SMS認証など追加手順をユーザーが目視・操作できる必要がある。却下: headless:true。
- 2026-11-09: セッション保存(.session.json)採用。理由: 実行のたびにSMS認証が必要になる問題を回避。却下: 毎回ログイン。
- 2026-11-09: ボタンクリック非依存のJS直接実行採用。理由: cfEXPY_checkLoadEnd()チェックでclickが失敗するケースがある。却下: force:trueのclick()。
- 2026-11-09: waitForLoadState('load')採用。理由: サイトがバックグラウンドで継続通信するためnetworkidleがタイムアウトする。却下: networkidle。
- 2026-11-09: dotenv(.env)による認証情報管理採用。理由: Safari iCloudキーチェーンにsecurityコマンドでアクセス不可。却下: Keychain連携。
- 2026-11-09: 先頭行innerText変化によるページ遷移検出採用。理由: 行数比較では同件数ページで誤検知する。却下: 行数比較。
- 2026-11-09: リクエスト間隔1.5秒デフォルト採用。理由: サーバー負荷への配慮（スクレイピングマナー）。却下: 無制限連続処理。
