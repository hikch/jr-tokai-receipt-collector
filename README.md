# JR東海領収書自動収集

JR東海のEX予約サイトから領収書PDFを自動収集するツール。
複数ページの利用履歴から一括で領収書PDFをダウンロードできます。

## 🚀 クイックスタート

### 1. 事前準備
1. **Safariの設定を変更**
   - Safari > 開発 > 「Apple EventsからのJavaScriptを許可」をオンにする
   
2. **EX予約サイトにログイン**
   - [JR東海EX予約](https://jr-central.co.jp)にログインする
   - 利用履歴一覧で取得したい期間を指定する
   - 該当期間の利用履歴一覧ページを表示する

### 2. 実行方法

**全件自動処理（推奨）:**
```bash
./run.sh
```

**単件テスト実行:**
```bash
DRY_RUN=true ./run.sh
```

## ⚙️ 設定オプション

環境変数で動作をカスタマイズできます：

| 変数名 | デフォルト値 | 説明 |
|--------|-------------|------|
| `SAVE_DIR` | `~/Desktop/Receipts/JRC` | PDF保存先ディレクトリ |
| `DRY_RUN` | `false` | `true`にするとプレビューのみ（実際の処理なし） |
| `PROCESS_ALL` | `true` | `false`にすると最初の1件のみ処理 |

**使用例:**
```bash
# 保存先を変更
SAVE_DIR="~/Documents/Receipts" ./run.sh

# プレビューモード
DRY_RUN=true ./run.sh

# 1件のみテスト実行
PROCESS_ALL=false ./run.sh
```

## 📁 生成されるファイル

領収書PDFは以下の形式で保存されます：
```
乗車日_お預かり番号.pdf
YYYY-MM-DD_お預かり番号.pdf

例: 2025-07-26_2026.pdf
（2025年7月26日乗車、お預かり番号2026の領収書）
```

## ❗ 注意事項

- **期間指定**: EX予約サイトで事前に取得したい期間を選択してから実行してください（例：2024年1月〜2024年12月）
- **画面確認**: Safariが前面にあるウィンドウでEX予約の利用履歴一覧ページを開いておく必要があります
- **操作禁止**: 処理中はSafariを操作しないでください
- **処理時間**: 大量の履歴がある場合、処理に時間がかかることがあります
- **ファイル上書き**: 既存の同名ファイルは上書きされます

## 🆘 トラブルシューティング

**エラー: "Allow JavaScript from Apple Events"**
→ Safari > 開発メニュー > 該当項目をオンにしてください

**領収書が見つからない**
→ 利用履歴一覧ページで「領収書表示」ボタンがある項目のみ処理されます

**処理が途中で止まる**
→ ネットワークの問題やサイトの応答遅延が原因の可能性があります。しばらく待ってから再実行してください
