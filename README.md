# JR東海領収書自動収集

JR東海のEX予約サイトから領収書PDFを自動収集するツール。
Playwright (Chromium) でブラウザを操作し、印刷ダイアログなしに直接PDF保存します。

## 🚀 クイックスタート

### 1. セットアップ（初回のみ）

```bash
npm install
npx playwright install chromium

cp .env.example .env
# .env を編集して認証情報・保存先・宛名を設定
```

### 2. 実行

```bash
./run.sh
# または
node collect.js
```

初回はSMS認証などの追加手順が必要です。ブラウザで認証を完了し、
利用履歴一覧ページを表示してから Enter を押してください。
2回目以降はセッションが保存されるため、認証手順はスキップされます。

## ⚙️ 設定（`.env`）

```bash
# 認証情報（必須）
EX_USER_ID=0000000000
EX_PASSWORD=yourpassword

# PDF保存先（省略時: ~/Desktop/Receipts/JRC）
SAVE_DIR=./2025

# 領収書宛名（省略時は空欄）
RECEIPT_NAME_LINE1=株式会社サンプル
# RECEIPT_NAME_LINE2=経理部

# リクエスト間隔ミリ秒（省略時: 1500）
# REQUEST_INTERVAL_MS=2000
```

`SAVE_DIR` は `~`・絶対パス・相対パス（実行ディレクトリ基準）すべて使用可能です。

## 📁 生成されるファイル

```
乗車日_お預かり番号.pdf
YYYY-MM-DD_お預かり番号.pdf

例: 2025-07-26_2026.pdf
（2025年7月26日乗車、お預かり番号2026の領収書）
```

> **注意**: 日付は**購入日ではなく乗車日**です。

## ❗ 注意事項

- **期間指定**: EX予約サイトで表示している期間の全データを処理します。事前にサイト側で期間を絞り込んでください。
- **操作禁止**: 処理中はブラウザを操作しないでください。
- **ファイル上書き**: 既存の同名ファイルは上書きされます。
- **宛名エラー**: 宛名を設定しているのに入力欄が見つからない場合は処理が中止されます。

## 🆘 トラブルシューティング

**認証情報エラー**
→ `.env` の `EX_USER_ID` と `EX_PASSWORD` を確認してください。

**セッション切れ**
→ `.session.json` を削除して再実行するとログインからやり直せます。

**領収書が見つからない**
→ 利用履歴一覧で「領収書表示」ボタンがある項目のみ処理されます。

**処理が途中で止まる**
→ ネットワークの問題やサイトの応答遅延が原因の可能性があります。しばらく待ってから再実行してください。
